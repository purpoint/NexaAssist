## Purpose

Prompts are product surface, not incidental strings. They are versioned here in
the repository, reviewed like code, and referenced from the implementation
rather than inlined across it.

## Conventions (to apply when prompts are introduced)

- One file or named constant per prompt; no prompt text scattered inline.
- Every prompt records its intended model, its inputs, and its expected output
  shape.
- Changes to a prompt are accompanied by the evaluation that justified them.
